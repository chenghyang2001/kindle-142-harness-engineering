# ch00｜導論與環境準備：把 HarnessLab 跑起來

## 這章在講什麼

- 全書的主張：正式上線的 AI 代理系統，真正決定安全的不是一句聰明的提示詞、也不是某個模型，而是包在外面的 **Harness（控制平面）**：它決定代理能知道什麼、記住什麼、做什麼決定、把權限委派給誰、執行什麼、被誰看見、怎麼恢復。
- 「長時程」與「多代理」是兩個放大器：跑得愈久，世界變化愈多；代理愈多，權限與上下文就愈容易互相傳染。
- 作者附了一個實驗室 repo **HarnessLab**：純 Python、零外部套件、不需要雲端帳號與付費 API。每章一個可執行情境（scenario），結果是一個 `LabResult`，裡面的 `decisions` 與 `artifacts` 就是教材本體。
- 每個決策只有五種：allow（放行）、deny（擋下）、escalate（交給人核准）、warn（繼續但警示）、rewrite（改寫成安全版本再執行）。

## 作者做過的實驗／例子

- 作者建議的學習順序是「跑 → 看 → 擴充 → 檢討」：先只看 JSON 輸出、不看程式碼，找出哪個決策是危險路徑、哪個產物是稽核人員會在意的；再去看 scenario.py 找出改變結果的那道控制。
- 每章都附一份實際跑出的結果（`chapters/chNN/LabResult/`），讓你拿新跑的結果對照。
- 書名中的 Harness 本意是「馬具／安全帶」：不是被動包住模型的外殼，而是用來約束、引導、傳導力量的結構。

## 演練

> 說明：練習視窗工作目錄是 practice/，裡面有書附實驗室副本 `HarnessLab/`（作者公開，Apache-2.0）。
> 執行章節一律用子殼層：`(cd HarnessLab && PYTHONUTF8=1 python -m harnesslab.cli run ch01 --json)`；自己寫的腳本放在 chNN/，在 practice 目錄用 `PYTHONUTF8=1 PYTHONPATH="HarnessLab;." python chNN/xxx.py` 執行（分號是 Windows 的路徑分隔）。不需要 pip install，也不要連網。
> 真實模型步驟：`llm_agent.py` 用 `claude -p`（Claude Code 無頭模式，走 Max 訂閱、不用 API 金鑰）扮演子代理；腳本內 `from llm_agent import ask, ask_json`。每個練習呼叫不超過 3 次。

### 練習 1：一次跑完十章，做出全書總覽表

**目的**：確認環境可用，並第一次看到「每章都是一組控制決策」的全貌。
**送給練習視窗的提示詞**：

```text
請在 HarnessLab/ 底下實際執行：
(cd HarnessLab && PYTHONUTF8=1 python -m harnesslab.cli list)
(cd HarnessLab && PYTHONUTF8=1 python -m harnesslab.cli run all) 把輸出存到 ch00/run-all.txt
(cd HarnessLab && PYTHONUTF8=1 python -m harnesslab.cli run all --json) 把輸出存到 ch00/run-all.json
接著寫一支小腳本 ch00/summarize.py（標準函式庫即可），讀 ch00/run-all.json，統計每章的 score 與 allow／deny／escalate／warn／rewrite 各有幾個，並在 practice 目錄執行它。
把結果整理成 ch00/overview.md：一張表（章、英文章名、繁中章名你自己翻、score、五種決策數量），表下用 3～5 句話說明：哪一章非 allow 決策比例最高、哪一章分數不是 1.0、你猜為什麼。數字一律來自腳本輸出，不可手填。
最後做一次子代理冒煙測試（只呼叫 1 次）：echo "用一句繁體中文說明什麼是 AI 代理的控制平面" | PYTHONUTF8=1 python llm_agent.py，把回覆附在 overview.md 最後的「子代理連線測試」小節。
```

**觀察重點**：

- 它是否真的執行了指令，數字是腳本算出來的而不是自己估的？
- 有沒有注意到 ch01 分數是 0.98（全書唯一不是 1.0）？
- 子代理測試是否真的有模型回覆（不是它自己寫的一句話）？
- 對「非 allow 比例高」的解讀是否合理（擋得多不代表系統差，代表控制有在作用）？

### 練習 2：五種決策與四組列舉值的白話詞彙表

**目的**：建立後面每章都會用到的共同詞彙，而且每個詞都找得到真實例子。
**送給練習視窗的提示詞**：

```text
請實際讀 HarnessLab/WORKBOOK.md 的第 2 節，以及 HarnessLab/harnesslab/core.py 開頭的四個列舉：Decision、TrustTier、DataClass、ActionRisk。
寫出 ch00/vocab.md，四個小節各一張表：英文值、建議的繁體中文譯名、一句白話解釋（給沒寫過程式的人看）、從 ch00/run-all.json 找到的一個真實例子（寫出章號與該筆 decision 的 reason 原句；某個值在輸出中找不到例子就寫「本次輸出無例子」，不可編造）。
最後加一段「ActionRisk 的風險排序」：依 core.py 裡 IntentVerifier.risk_order 的數字由低到高列出，並說明為什麼「對外溝通」被排在「可逆寫入」之上、「不可逆寫入」之下。
```

**觀察重點**：

- 例子是否真的能在 run-all.json 裡找到（可抽查 reason 原句）？
- 有沒有誠實標出找不到例子的值？
- 風險排序是否照程式碼的數字，而不是憑感覺？

## 教練解說要點

- 這本書的學習單位不是「名詞」，而是「決策」：每一筆 allow／deny／escalate／warn／rewrite 都對應一道控制。
- 五種決策中 escalate 與 rewrite 最值得注意：前者把人放回迴圈，後者讓工作在安全範圍內繼續，不是一律擋死。
- 後面每章都照「跑 → 看 → 擴充 → 檢討」：先跑原情境，再自己寫小實驗去戳它的邊界。
